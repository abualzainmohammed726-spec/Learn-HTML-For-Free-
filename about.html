What is this?

HTML Mastery is an interactive learning tool built to help beginners understand the core building blocks of the web. It combines static examples with live code playgrounds so you can experiment and see results immediately.

The project uses a clean, dark theme and is fully responsive – it works great on both desktop and mobile devices.

Technologies used

  • HTML5
  • CSS3 (custom properties, flexbox, grid)
  • Vanilla JavaScript
  • Discord Webhook (for sign‑up demo)

Made with ❤️ for learning and teaching.
